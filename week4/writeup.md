| Test | All npm scripts chain steps with `;`, which assumes a POSIX shell. Working commands on Windows: `npx coffee --compile Base58.coffee`, then `npx mocha` (mocha suite in `test/bs58.js`, 33 passing) and `npx coffee Base58.node.test.coffee` (tape suite, 35/35 passing). Alternatively `npm test --script-shell="C:\Program Files\Git\bin\bash.exe"` runs both suites, but the last step, `open window.html`, is macOS-only and fails (use `start window.html` on Windows after `npx browserify Base58.window.test.js > window.js`). On macOS/Linux, `npm test` works as written. |
| Lint / format | None: no linter, formatter, config file, or lint script. |
| Key directories and entry points | Flat repo. `Base58.coffee` is the source; `Base58.js` is its compiled output. `Base58_Test.coffee` exports `(tape, Base58) ->` shared tests, run by `Base58.node.test.coffee` (Node) and `Base58.window.test.coffee` (browser). `window_test_harness.coffee` + `window.html` are a custom browser tape reporter. `test/bs58.js` + `test/fixtures.json` are the mocha compatibility suite from the original `cryptocoinjs/bs58`. |
